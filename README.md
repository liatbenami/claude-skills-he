# סקילים לקלוד — דפי נחיתה ומערכות הרשמה בעברית

שני סקילים ל-[Claude Code](https://claude.com/claude-code) שבונים דפי נחיתה בעברית (RTL) ומערכות הרשמה לסדנאות, ריטריטים ואירועים.

הם נוצרו מתוך פרויקט אמיתי, וכוללים את כל המלכודות שהתגלו בו בדרך — מספרים שמתהפכים על המסך, פריסות שלא נכנסות לתוקף, וטלפונים שמאבדים את ה-0 המוביל.

## מה יש כאן

### `landing-page-he` — דף נחיתה

עמוד HTML אחד, עצמאי, מעוצב ומותאם לנייד.

- מערכת עיצוב: פלטות לתחומים שונים, גופנים עבריים, ודגימת צבע אוטומטית מתוך לוגו
- שבעה רכיבים מוכנים: הדר דביק, הירו, אליפסות פרטים בזיגזג, לוח זמנים, כרטיסיות מנחים, הרשמה, כפתור וואטסאפ צף
- שמונה מלכודות RTL ונייד, כל אחת עם תסמין, סיבה ותיקון
- בודק אוטומטי שמריץ 12 בדיקות על הדף המוגמר

### `registration-system-he` — מערכת הרשמות

טופס שבאמת נשמר, על תשתית חינמית של גוגל.

- שמירה לגוגל-שיט דרך Google Apps Script — בלי שרת ובלי עלות
- מייל אישור לנרשמת עם קישור תשלום, והתראה למנהלת
- הגבלת תפוסה שמתעלמת מהרשמות שבוטלו, כך שביטול מפנה מקום אמיתי
- רשימת המתנה אוטומטית: גיליון שנוצר לבד, תור, והעלאה כשמתפנה מקום
- הוראות פריסה בעברית, מוכנות לשליחה, עם תוויות הממשק בשתי השפות
- 21 בדיקות לוגיקה שרצות על גיליון מדומה, בלי לגעת בנתונים אמיתיים

שני הסקילים עצמאיים. אפשר דף בלי מערכת, ואפשר להוסיף מערכת לדף קיים.

## התקנה

```bash
git clone https://github.com/liatbenami/claude-skills-he.git
cp -r claude-skills-he/skills/* ~/.claude/skills/
```

בווינדוס (PowerShell):

```powershell
git clone https://github.com/liatbenami/claude-skills-he.git
Copy-Item -Recurse claude-skills-he\skills\* "$env:USERPROFILE\.claude\skills\"
```

להתקנה של אחד בלבד — להעתיק רק את התיקייה שלו.

## שימוש

לא צריך להפעיל כלום. פותחים את קלוד ומבקשים בשפה רגילה:

> תבני לי דף נחיתה לסדנת לידה שאני מעבירה בינואר

> אני רוצה שההרשמות מהטופס יישמרו אצלי בגוגל-שיט ושכל נרשמת תקבל מייל אישור

קלוד יזהה את הסקיל המתאים, ישאל כמה שאלות קצרות, ויבנה.

## למי זה מיועד

**למנחות ובעלות עסק קטן שאינן מתכנתות.** הסקילים כתובים כך שקלוד ישאל בעברית פשוטה, יבנה גרסה ראשונה מהר, ויפתח אותה בדפדפן — במקום לתאר קוד.

נקודה אחת שחשוב לדעת מראש: את החלק של Google Apps Script אי אפשר להקים עבור מישהי אחרת, כי הוא יושב בתוך חשבון הגוגל שלה. קלוד כותב את הקוד ואת ההוראות, וההדבקה והפריסה הן כ-5 דקות של עבודה שלה. הסקיל אומר את זה בפירוש בהתחלה, כדי שזו לא תהיה הפתעה.
